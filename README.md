# IT Labs Portfolio

Hands-on IT labs covering networking, troubleshooting, systems administration, cloud, and technical support.

This repository documents practical exercises completed while developing skills for junior IT Support, Service Desk, Desktop Support, and Networking roles.

## Networking Labs

| Lab | Focus |
|---|---|
| [01 - VLAN 10 Media DHCP](networking/01-vlan-dhcp-media/) | VLAN and DHCP practice in Cisco Packet Tracer |
| [02 - Basic LAN Connectivity and Switch Management](networking/02-basic-lan-connectivity-switch-management/) | Cisco IOS configuration, IPv4 addressing, switch management, NVRAM persistence, and ping validation |

Each lab is documented with its objective, configuration approach, troubleshooting notes, validation results, and supporting evidence where available.
